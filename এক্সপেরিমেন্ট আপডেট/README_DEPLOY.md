# Employee Monitoring System — Render + GitHub Ready

## Render deploy
1. Push this folder to a GitHub repository.
2. In Render, create a **Web Service** from that repository.
3. Render can use `render.yaml`, or set:
   - Build Command: `npm install --omit=dev`
   - Start Command: `npm start`
   - Health Check Path: `/health`
4. Do not set a fixed port in Render; the app reads Render's `PORT` automatically.
5. `JWT_SECRET` is generated by `render.yaml`. If you configure it manually, use a long random value.

The app serves the frontend from the same Node server. The frontend therefore uses the deployed domain instead of hard-coded `localhost:5000`.

## Important data note
The included database is a local JSON file. On free/ephemeral hosting, local files are not a reliable permanent database and may reset after a redeploy or instance replacement. For production data, use a persistent database or persistent disk.

## GitHub
- `node_modules/`, logs, `.env`, and runtime JSON data are ignored.
- GitHub does **not** have a 100-file limit. The commonly confused limit is about a **100 MB individual file**. Large files should use Git LFS or external storage.
