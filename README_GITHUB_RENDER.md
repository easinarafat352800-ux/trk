# GitHub + Render deployment

IMPORTANT: upload the CONTENTS of this folder to the ROOT of the GitHub repository.
Do not put all these files inside another folder.

The repository root must directly contain:
- package.json
- server.js
- local-db.js
- frontend_with_backend.html
- render.yaml
- Dockerfile
- .env.example

Render:
- Runtime: Node
- Build Command: npm install --omit=dev
- Start Command: npm start
- Health Check Path: /health
- Do NOT manually set PORT; Render supplies it.
- JWT_SECRET can be generated by render.yaml.

The local JSON database is created automatically at runtime.
